🍬 Saini Sweet Shop
A modern, responsive and user-friendly Sweet Shop & Food Website built to showcase delicious sweets, fast food, beverages, and other food items.

The Saini Sweet Shop website provides a clean interface where users can explore different food categories, view products, browse the gallery, learn about the shop, and get contact information.

🌐 Project Overview
Saini Sweet Shop is a frontend web development project created using HTML5, CSS3, and JavaScript.

The website contains multiple pages and a collection of food and sweet images to provide an attractive and engaging experience for visitors.

🚀 How to Run the Project
1. Clone the Repository
git clone https://github.com/Nitinsaini112/Saini-Sweet-Shop.git

2. Open the Project
cd Saini-Sweet-Shop

3. Run the Website
Open the following file in your browser:

index.html

You can also use VS Code Live Server to run the project.

💻 Run Using VS Code
Open the project in Visual Studio Code.

Install the Live Server extension.

Right-click on index.html.

Select Open with Live Server.

The website will open in your browser.
